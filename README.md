## 我在意的事

- **能跑起来比写得漂亮重要。** 每个仓库都要有 README、LICENSE、CI，别人 `git clone` 之后三分钟内能跑通。
- **评分要可解释。** 一个数字没有理由，就只是噪音。
- **拆开看过的东西才算懂。** 逆向、抓包、读字节码，都是为了回答"它到底怎么工作的"。
